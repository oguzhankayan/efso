# Efso App Store Screenshot Promptları

## Ortak Tasarım Dili (her prompt'a ekle)

Style: deep dark purple-black background (#0A0612 → #1A0E2E). Y2K-inspired holographic accents (pink-to-lime-to-blue gradient) used sparingly on glows, borders, and highlight words. Bold lowercase sans-serif typography for headlines. Soft purple glow halos behind iPhone mockup. Glass morphism hints. iPhone 15 Pro mockup with dark bezels. Turkish language text exactly as written — do not translate or alter. Premium, confident, minimal mood. No emoji in caption text. The provided reference image must be placed INSIDE the iPhone mockup screen as the app's actual UI. Do not recreate or reimagine the app UI — use the reference image exactly as-is inside the phone screen.
